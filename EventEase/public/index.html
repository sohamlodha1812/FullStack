About EventEase

EventEase is a student mini-project built to help college students easily discover, explore, and register for campus events. Built with Node.js, Express, MongoDB, and plain HTML/CSS/JavaScript — no heavy frameworks.

  • ✅ Browse all upcoming college events
  • ✅ One-click registration with instant confirmation
  • ✅ Duplicate registration prevention
  • ✅ Admin dashboard to view all registrations
  • ✅ Fully responsive — works on mobile and desktop
